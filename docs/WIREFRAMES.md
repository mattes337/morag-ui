## Design System

### Color Palette
```
Primary Colors:
- Primary: #3B82F6 (Blue)
- Secondary: #8B5CF6 (Purple)
- Accent: #10B981 (Green)

Neutral Colors:
- Background: #FFFFFF / #111827 (Light/Dark)
- Surface: #F9FAFB / #1F2937
- Border: #E5E7EB / #374151
- Text Primary: #111827 / #F9FAFB
- Text Secondary: #6B7280 / #9CA3AF

Status Colors:
- Success: #10B981
- Warning: #F59E0B
- Error: #EF4444
- Info: #3B82F6
```

### Typography
```
Headings:
- H1: 36px/44px (2.25rem/2.75rem) - Bold
- H2: 30px/36px (1.875rem/2.25rem) - Semibold
- H3: 24px/32px (1.5rem/2rem) - Semibold
- H4: 20px/28px (1.25rem/1.75rem) - Medium

Body:
- Large: 18px/28px (1.125rem/1.75rem)
- Regular: 16px/24px (1rem/1.5rem)
- Small: 14px/20px (0.875rem/1.25rem)
- Caption: 12px/16px (0.75rem/1rem)
```
